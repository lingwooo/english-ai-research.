# English & AI — практика английского для взрослых

Сайт собран для взрослых, которым нужно заниматься в своём темпе: здесь есть 3D-мини-игра «Забег Фокси», AI-тьютор, полезные повседневные слова и личный словарь. В игре Фокси переключается между тремя дорожками, прыгает через преграды и выбирает правильную форму слова; на заданиях темп замедляется, а игру можно развернуть на весь экран. Кнопки темы переключают светлый и тёмный вид, размер текста и список сохранённых слов запоминаются в браузере на устройстве.

## Публикация сайта

GitHub Actions автоматически публикует `index.html` в GitHub Pages после изменений в `main`. GitHub Pages размещает только статическую версию интерфейса; для ответов AI нужен отдельно размещённый сервер с `OPENAI_API_KEY`. Ключ нельзя помещать в этот репозиторий. На опубликованной странице это ограничение показано рядом с AI-тьютором.

## Запуск AI-тьютора на Windows

Для ответов AI нужны Node.js 18+ и API-ключ OpenAI Platform. Ключ не вставляется в HTML и не отправляется из браузера напрямую: локальный сервер читает его из переменной окружения.

1. Создайте API-ключ в [OpenAI Platform](https://platform.openai.com/api-keys). Использование API тарифицируется отдельно по его условиям.
2. Откройте PowerShell в папке проекта и выполните:

```powershell
$secureKey = Read-Host "OpenAI API key" -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new("", $secureKey).Password
$secureKey = $null
node .\server.mjs
Remove-Item Env:OPENAI_API_KEY
```

3. Откройте в браузере <http://127.0.0.1:3000>.
4. Оставьте окно PowerShell открытым, пока пользуетесь тьютором. Нажмите `Ctrl+C`, чтобы остановить сервер.

Не вставляйте API-ключ в `index.html`, публичный репозиторий или чат. Переписка передаётся в OpenAI API для генерации ответов. Сайт сам не записывает её на диск; текущая история находится только в памяти открытой страницы. Распознавание микрофона выполняется браузером и зависит от его поставщика и настроек.

Голосовой ввод использует Web Speech API, поэтому браузер может запросить доступ к микрофону; при отсутствии поддержки можно печатать. Короткие ответы озвучиваются встроенным синтезом речи браузера.

Для смены модели задайте `OPENAI_MODEL` в том же окне PowerShell перед запуском. По умолчанию используется `gpt-5.6-luna`.
