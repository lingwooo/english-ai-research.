# Foxly — английский для взрослых без стресса

Foxly — спокойная практика английского для работы, поездок и повседневной жизни. На сайте есть короткий тест уровня, озвученные фразы, игра-бегалка с Фокси, грамматические подсказки и план занятий на месяц.

## Что есть на сайте

- Тест уровня из шести вопросов.
- Фразы по темам «Работа», «Поездки» и «Каждый день» с переводом и озвучкой.
- Foxly Run: собирай предложения, меняй дорожки, перепрыгивай барьеры и подныривай под балки.
- Светлая и тёмная темы.
- Офлайн-подсказки по основам английской грамматики.
- Прогресс фраз и рекорд игры сохраняются в браузере на устройстве.

## Публикация

Сайт состоит из статических HTML-файлов и публикуется через GitHub Pages. Главная страница — index.html, игровая страница — foxi-game.html. Помощник Foxly даёт встроенные подсказки и не отправляет сообщения на внешний сервер.
